# Development workflow

1. Inspect the current repository before editing.
2. Confirm whether the request authorizes page or shared-component work.
3. Work in the existing `ouranos` repository and Cloudflare Worker.
4. Keep changes within the requested scope.
5. Run type checks and production build before deployment.
6. Do not deploy to production unless explicitly instructed.
7. Record architectural or dependency changes in the relevant documentation.
